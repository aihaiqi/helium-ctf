# helium-ctf
Helium-CTF— a competition workbench for CTF players: Vue3 website (tool library, event calendar, downloads) + Electron desktop launcher with tray, global hotkey and 74 offline plugins covering encoding, crypto, web, forensics and misc, plus Web/Pwn/Reverse/Crypto/Misc challenge workbenches. Offline-first: look up events online, solve offline.
