# Ironclad

Every month, Patch Tuesday drops something like a thousand Windows CVEs. With numbers like that, every one of you must have at least one Windows kernel 0day lying around in a private folder named totally_not_0days/, right?

So here's the deal. We wrote a small, humble, absolutely bug-free* driver and loaded it into a fully patched Windows 11. Become SYSTEM, read the flag. Use our bug, use your bug, or burn the 0day you were saving for Pwn2Own. We don't judge ^^

Instancer: https://thisisawindowskernelpwnchallenge.net/

This challenge is running on Windows 11 26H2, 26300.9818

Upload your poc.exe, we run it, you get a screenshot. Each team only gets 3 submissions, so choose your 0day wisely...
